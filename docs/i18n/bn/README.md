# Stocks Exporter

[![Quality Gate Status](https://sonarcloud.io/api/project_badges/measure?project=somethingwithproof_StocksExporter&metric=alert_status)](https://sonarcloud.io/summary/new_code?id=somethingwithproof_StocksExporter)
[![License](https://img.shields.io/badge/license-MIT-blue)](../../../LICENSE)
[![OpenSSF Scorecard](https://api.scorecard.dev/projects/github.com/somethingwithproof/StocksExporter/badge)](https://scorecard.dev/viewer/?uri=github.com/somethingwithproof/StocksExporter)

আপনার Apple Stocks ওয়াচলিস্টকে CSV বা JSON ফরম্যাটে এক্সপোর্ট করার জন্য একটি নেটিভ macOS অ্যাপ।

Apple আপনার Stocks ওয়াচলিস্টের ডেটা এক্সপোর্ট করার কোনো আনুষ্ঠানিক উপায় প্রদান করে না। এই অ্যাপটি দুটি পরিপূরক পদ্ধতির মাধ্যমে সেই সমস্যার সমাধান করে:

1. **অ্যাক্সেসিবিলিটি API (Accessibility API)** — চলমান Stocks.app ইন্টারফেস রিয়েল-টাইমে পড়ে
2. **উইজেট ক্যাশে (Widget Cache)** — অ্যাপ চালু না থাকলে স্থানীয়ভাবে সংরক্ষিত ক্যাশে ফাইল পার্স করে

## বৈশিষ্ট্যসমূহ

- **নেটিভ SwiftUI ইন্টারফেস** ডার্ক মোড এবং RTL লেআউট সমর্থনসহ
- **একাধিক ডেটা উৎস** — অ্যাক্সেসিবিলিটি API বা ক্যাশে পার্সিং
- **CSV বা JSON-এ এক্সপোর্ট** কাস্টমাইজযোগ্য কলামসহ
- **এক্সপোর্টের আগে প্রিভিউ** — আপনি ঠিক কী এক্সপোর্ট করছেন তা আগে দেখুন
- **কলাম নির্বাচন** — কোন ডেটা ক্ষেত্রগুলো অন্তর্ভুক্ত করবেন তা বেছে নিন
- **ক্লিপবোর্ডে কপি করুন** — ফাইল সংরক্ষণ না করেই দ্রুত এক্সপোর্ট
- **স্থায়ী পছন্দসমূহ** — আপনার এক্সপোর্ট সেটিংস মনে রাখে
- **স্থানীয়কৃত ইন্টারফেস** — ৪৫টি ভাষায় উপলব্ধ

## সমর্থিত ভাষাসমূহ

Stocks Exporter macOS সিস্টেমের ভাষা পছন্দ ব্যবহার করে এবং ৪৫টি ভাষার জন্য সম্পূর্ণ UI স্থানীয়করণ অন্তর্ভুক্ত করে (আরবি, ফার্সি, হিব্রু এবং উর্দুর জন্য স্বয়ংক্রিয় ডান-থেকে-বাম লেআউট সমর্থনসহ)। সম্পূর্ণ তালিকার জন্য [ইংরেজি README](../../../README.md#supported-languages) দেখুন।

## প্রয়োজনীয়তা

- macOS 14.0 (Sonoma) বা তার পরবর্তী সংস্করণ
- অ্যাক্সেসিবিলিটি অনুমতি (Stocks.app থেকে সরাসরি ডেটার জন্য)

## বিল্ড করা

```bash
swift build
swift run
```

অথবা Xcode-এ খুলে বিল্ড করুন।

## ব্যবহারবিধি

1. অ্যাপটি চালু করুন
2. অনুরোধ করা হলে অ্যাক্সেসিবিলিটি অনুমতি দিন (সরাসরি ডেটার জন্য)
3. Apple Stocks অ্যাপ খুলুন (ঐচ্ছিক, সেরা ফলাফলের জন্য)
4. আপনার ওয়াচলিস্ট লোড করতে রিফ্রেশ করুন-এ ক্লিক করুন
5. শেয়ার নির্বাচন করুন (অথবা সবগুলো এক্সপোর্ট করুন)
6. এক্সপোর্ট-এ ক্লিক করুন এবং আপনার ফরম্যাট নির্বাচন করুন

## গোপনীয়তা

এই অ্যাপটি:

- শুধুমাত্র Apple-এর Stocks অ্যাপ থেকে ডেটা পড়ে
- ইন্টারনেটের সাথে সংযোগ করে না
- কোনো ডেটা সংগ্রহ বা প্রেরণ করে না
- সমস্ত প্রক্রিয়াকরণ আপনার Mac-এ স্থানীয়ভাবে সম্পন্ন করে
