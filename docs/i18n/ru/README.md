# Stocks Exporter

[![OpenSSF Scorecard](https://api.scorecard.dev/projects/github.com/somethingwithproof/StocksExporter/badge)](https://scorecard.dev/viewer/?uri=github.com/somethingwithproof/StocksExporter)

Нативное приложение для macOS, позволяющее экспортировать список наблюдения Apple Stocks в формат CSV или JSON.

Apple не предоставляет официального способа экспортировать данные списка наблюдения Stocks. Это приложение решает задачу двумя взаимодополняющими способами:

1. **API универсального доступа** — считывает интерфейс запущенного приложения Stocks.app в реальном времени
2. **Кэш виджета** — разбирает локально сохранённые файлы кэша, когда приложение не запущено

## Возможности

- **Нативный интерфейс SwiftUI** с поддержкой тёмной темы и разметки RTL
- **Несколько источников данных** — API универсального доступа или разбор кэша
- **Экспорт в CSV или JSON** с настраиваемыми столбцами
- **Предпросмотр перед экспортом** — проверяйте экспортируемые данные заранее
- **Выбор столбцов** — выбирайте, какие поля данных включать
- **Копирование в буфер обмена** — быстрый экспорт без сохранения файла
- **Сохранение настроек** — запоминает параметры экспорта
- **Локализованный интерфейс** — доступно на 45 языках

## Поддерживаемые языки

Stocks Exporter использует системные языковые настройки macOS и включает полную локализацию для 45 языков (включая автоматическую поддержку письма справа налево для арабского, персидского, иврита и урду). Полный список языков приведён в [англоязычном README](../../../README.md#supported-languages).

## Требования

- macOS 14.0 (Sonoma) или новее
- Разрешение «Универсальный доступ» (для получения данных в реальном времени из Stocks.app)

## Сборка

```bash
swift build
swift run
```

Или откройте проект в Xcode и выполните сборку.

## Использование

1. Запустите приложение
2. Предоставьте разрешение универсального доступа при запросе (для данных в реальном времени)
3. Откройте приложение Apple Stocks (необязательно, для наилучшего результата)
4. Нажмите «Обновить», чтобы загрузить список наблюдения
5. Выберите нужные акции (или экспортируйте все)
6. Нажмите «Экспорт» и выберите формат

## Конфиденциальность

Это приложение:

- Считывает данные только из приложения Apple Stocks
- Не подключается к интернету
- Не собирает и не передаёт никакие данные
- Выполняет всю обработку локально на вашем Mac
