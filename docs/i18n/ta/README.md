உங்கள் Apple Stocks கண்காணிப்புப் பட்டியலை CSV அல்லது JSON வடிவத்தில் ஏற்றுமதி செய்ய உதவும் இயல்பான macOS செயலி.

உங்கள் Stocks கண்காணிப்புப் பட்டியல் தரவை ஏற்றுமதி செய்ய Apple அதிகாரப்பூர்வ வழியை வழங்கவில்லை. இந்தச் செயலி ஒன்றுக்கொன்று துணையான இரு முறைகளைப் பயன்படுத்தி அந்தச் சிக்கலைத் தீர்க்கிறது:

1. **அணுகல்தன்மை API (Accessibility API)** — இயங்கிக் கொண்டிருக்கும் Stocks.app இடைமுகத்தை நிகழ்நேரத்தில் படிக்கிறது
2. **விட்ஜெட் தற்காலிகச் சேமிப்பு (Widget Cache)** — செயலி இயங்காதபோது கணினியில் சேமிக்கப்பட்ட தற்காலிகச் சேமிப்புக் கோப்புகளைப் பகுப்பாய்வு செய்கிறது

## சிறப்பம்சங்கள்

- **இயல்பான SwiftUI இடைமுகம்** — இருண்ட பயன்முறை மற்றும் RTL தளவமைப்பு ஆதரவுடன்
- **பல தரவு மூலங்கள்** — அணுகல்தன்மை API அல்லது தற்காலிகச் சேமிப்புப் பகுப்பாய்வு
- **CSV அல்லது JSON ஏற்றுமதி** — தனிப்பயனாக்கக்கூடிய நெடுவரிசைகளுடன்
- **ஏற்றுமதிக்கு முன் முன்னோட்டம்** — நீங்கள் என்ன ஏற்றுமதி செய்கிறீர்கள் என்பதைத் துல்லியமாகப் பாருங்கள்
- **நெடுவரிசைத் தேர்வு** — சேர்க்க வேண்டிய தரவுப் புலங்களைத் தேர்ந்தெடுங்கள்
- **இடைநிலைப் பலகையில் நகலெடு** — கோப்பைச் சேமிக்காமல் விரைவான ஏற்றுமதி
- **நிலையான விருப்பத்தேர்வுகள்** — உங்கள் ஏற்றுமதி அமைப்புகளை நினைவில் கொள்ளும்
- **உள்ளூர்மயமாக்கப்பட்ட இடைமுகம்** — 45 மொழிகளில் கிடைக்கிறது

## ஆதரிக்கப்படும் மொழிகள்

Stocks Exporter, macOS கணினி மொழி விருப்பங்களைப் பயன்படுத்துகிறது மற்றும் 45 மொழிகளுக்கான முழு இடைமுக மொழிபெயர்ப்பையும் உள்ளடக்கியுள்ளது (அரபு, பாரசீகம், எபிரேயம் மற்றும் உருது மொழிகளுக்கான தானியங்கி வலமிருந்து இடமாக தளவமைப்பு ஆதரவு உட்பட). முழுப் பட்டியலைக் காண [ஆங்கில README](../../../README.md#supported-languages) கோப்பைப் பார்க்கவும்.

- அணுகல்தன்மை அனுமதி (Stocks.app இலிருந்து நேரடித் தரவைப் பெற)

## பயன்பாடு

1. செயலியைத் திறக்கவும்
2. கேட்கப்படும்போது அணுகல்தன்மை அனுமதியை வழங்கவும் (நேரடித் தரவுக்கு)
3. Apple Stocks செயலியைத் திறக்கவும் (விருப்பத்திற்குரியது, சிறந்த முடிவுகளுக்கு)
4. உங்கள் கண்காணிப்புப் பட்டியலை ஏற்ற புதுப்பி என்பதைக் கிளிக் செய்யவும்
5. பங்குகளைத் தேர்ந்தெடுக்கவும் (அல்லது அனைத்தையும் ஏற்றுமதி செய்யவும்)
6. ஏற்றுமதி என்பதைக் கிளிக் செய்து வடிவத்தைத் தேர்ந்தெடுக்கவும்
