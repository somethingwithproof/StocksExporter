# Stocks Exporter

[![Quality Gate Status](https://sonarcloud.io/api/project_badges/measure?project=somethingwithproof_StocksExporter&metric=alert_status)](https://sonarcloud.io/summary/new_code?id=somethingwithproof_StocksExporter)

[![OpenSSF Scorecard](https://api.scorecard.dev/projects/github.com/somethingwithproof/StocksExporter/badge)](https://scorecard.dev/viewer/?uri=github.com/somethingwithproof/StocksExporter)

Нативна macOS апликација за извоз ваше Apple Stocks листе праћења у CSV или JSON формат.

Apple не нуди званичан начин за извоз података са листе праћења из апликације Stocks. Ова апликација решава тај проблем помоћу две допуњујуће методе:

1. **Accessibility API** - чита интерфејс покренуте апликације Stocks.app у реалном времену
2. **Кеш виџета** - обрађује локално сачуване кеш датотеке када апликација није покренута

## Функције

- **Нативни SwiftUI интерфејс** са подршком за тамни режим и RTL распоред
- **Више извора података** - Accessibility API или обрада кеша
- **Извоз у CSV или JSON** са прилагодљивим колонама
- **Преглед пре извоза** - погледајте тачно шта извозите
- **Избор колона** - изаберите која поља података желите да укључите
- **Копирање у оставу** - брзи извоз без чувања датотеке
- **Трајна подешавања** - памти ваша подешавања извоза
- **Локализовани интерфејс** - доступан на 48 језика

## Подржани језици

Stocks Exporter користи системска језичка подешавања macOS-а и укључује потпуну локализацију корисничког интерфејса за 48 језика (укључујући аутоматску подршку за распоред здесна налево за арапски, персијски, хебрејски и урду). Потпун списак језика погледајте у [енглеској датотеци README](../../../README.md#supported-languages).

## Захтеви

- macOS 14.0 (Sonoma) или новији
- Дозвола приступачности (за податке уживо из апликације Stocks.app)

## Изградња

```bash
swift build
swift run
```

Или отворите пројекат у Xcode-у и изградите га.

## Коришћење

1. Покрените апликацију
2. Одобрите дозволу приступачности када се то затражи (за податке уживо)
3. Отворите апликацију Apple Stocks (опционо, за најбоље резултате)
4. Кликните на Освежи да учитате листу праћења
5. Изаберите акције (или извезите све)
6. Кликните на Извези и изаберите формат

## Приватност

Ова апликација:

- Чита податке искључиво из Apple-ове апликације Stocks
- Не повезује се на интернет
- Не прикупља нити шаље никакве податке
- Сва обрада се одвија локално на вашем Mac рачунару
