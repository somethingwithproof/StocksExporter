# Stocks Exporter

Нативна програма для macOS для експорту списку спостереження Apple Stocks у формат CSV або JSON.

Apple не надає офіційного способу експортувати дані списку спостереження Stocks. Ця програма вирішує проблему за допомогою двох взаємодоповнювальних методів:

1. **API доступності** — зчитує інтерфейс запущеної програми Stocks.app у реальному часі
2. **Кеш віджета** — розбирає локально збережені файли кешу, коли програма не запущена

## Можливості

- **Нативний інтерфейс SwiftUI** із підтримкою темної теми та розмітки RTL
- **Кілька джерел даних** — API доступності або розбір кешу
- **Експорт у CSV або JSON** із налаштовуваними стовпцями
- **Попередній перегляд перед експортом** — бачите саме те, що експортуєте
- **Вибір стовпців** — обирайте потрібні поля даних
- **Копіювання до буфера обміну** — швидкий експорт без збереження файлу
- **Збереження налаштувань** — запам’ятовує параметри експорту
- **Локалізований інтерфейс** — доступно 45 мовами

## Підтримувані мови

Stocks Exporter використовує системні мовні параметри macOS і містить повну локалізацію для 45 мов (включно з автоматичною підтримкою напрямку справа наліво для арабської, перської, івриту та урду). Повний перелік дивіться в [англомовному README](../../../README.md#supported-languages).

## Вимоги

- macOS 14.0 (Sonoma) або новіша версія
- Дозвіл «Доступність» (для отримання даних у реальному часі зі Stocks.app)

## Збірка

```bash
swift build
swift run
```

Або відкрийте проєкт в Xcode та виконайте збірку.

## Використання

1. Запустіть програму
2. Надайте дозвіл «Доступність» за запитом (для даних у реальному часі)
3. Відкрийте програму Apple Stocks (необов’язково, для найкращого результату)
4. Натисніть «Оновити», щоб завантажити список спостереження
5. Виберіть акції (або експортуйте всі)
6. Натисніть «Експортувати» та оберіть формат

## Приватність

Ця програма:

- Зчитує дані лише з програми Apple Stocks
- Не підключається до інтернету
- Не збирає та не передає жодних даних
- Уся обробка відбувається локально на вашому Mac
