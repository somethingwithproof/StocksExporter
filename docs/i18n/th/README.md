# Stocks Exporter

[![Quality Gate Status](https://sonarcloud.io/api/project_badges/measure?project=somethingwithproof_StocksExporter&metric=alert_status)](https://sonarcloud.io/summary/new_code?id=somethingwithproof_StocksExporter)
[![License](https://img.shields.io/badge/license-MIT-blue)](../../../LICENSE)
[![OpenSSF Scorecard](https://api.scorecard.dev/projects/github.com/somethingwithproof/StocksExporter/badge)](https://scorecard.dev/viewer/?uri=github.com/somethingwithproof/StocksExporter)

แอป macOS แบบเนทีฟสำหรับส่งออกรายการเฝ้าดู Apple Stocks ของคุณเป็นรูปแบบ CSV หรือ JSON

Apple ไม่มีวิธีอย่างเป็นทางการในการส่งออกข้อมูลรายการเฝ้าดู Stocks แอปนี้ช่วยแก้ปัญหานี้ด้วยสองวิธีที่เสริมกัน:

1. **Accessibility API** — อ่านอินเทอร์เฟซของแอป Stocks.app ที่กำลังทำงานอยู่แบบเรียลไทม์
2. **แคชวิดเจ็ต (Widget Cache)** — แยกวิเคราะห์ไฟล์แคชที่จัดเก็บไว้ในเครื่องเมื่อแอปไม่ได้เปิดอยู่

## ฟีเจอร์

- **อินเทอร์เฟซ SwiftUI แบบเนทีฟ** รองรับโหมดมืดและเลย์เอาต์แบบ RTL
- **หลายแหล่งข้อมูล** — Accessibility API หรือการแยกวิเคราะห์แคช
- **ส่งออกเป็น CSV หรือ JSON** พร้อมคอลัมน์ที่ปรับแต่งได้
- **ดูตัวอย่างก่อนส่งออก** — ตรวจสอบข้อมูลที่จะส่งออกได้อย่างชัดเจน
- **เลือกคอลัมน์** — เลือกฟิลด์ข้อมูลที่ต้องการรวมไว้
- **คัดลอกไปยังคลิปบอร์ด** — ส่งออกอย่างรวดเร็วโดยไม่ต้องบันทึกไฟล์
- **จดจำการตั้งค่า** — บันทึกการตั้งค่าการส่งออกของคุณไว้
- **อินเทอร์เฟซหลายภาษา** — รองรับ 45 ภาษา

## ภาษาที่รองรับ

Stocks Exporter ใช้การตั้งค่าภาษาของระบบ macOS และมาพร้อมการแปลอินเทอร์เฟซครบถ้วน 45 ภาษา (รวมถึงการรองรับเลย์เอาต์จากขวาไปซ้ายโดยอัตโนมัติสำหรับภาษาอาหรับ เปอร์เซีย ฮีบรู และอูรดู) ดูรายการทั้งหมดได้ใน [README ภาษาอังกฤษ](../../../README.md#supported-languages)

## ความต้องการของระบบ

- macOS 14.0 (Sonoma) หรือใหม่กว่า
- สิทธิ์การช่วยการเข้าถึง (สำหรับข้อมูลแบบเรียลไทม์จาก Stocks.app)

## การบิลด์

```bash
swift build
swift run
```

หรือเปิดใน Xcode แล้วทำการบิลด์

## วิธีใช้งาน

1. เปิดแอป
2. อนุญาตสิทธิ์การช่วยการเข้าถึงเมื่อระบบร้องขอ (สำหรับข้อมูลแบบเรียลไทม์)
3. เปิดแอป Apple Stocks (ไม่บังคับ แต่แนะนำเพื่อผลลัพธ์ที่ดีที่สุด)
4. คลิกรีเฟรชเพื่อโหลดรายการเฝ้าดูของคุณ
5. เลือกหุ้น (หรือส่งออกทั้งหมด)
6. คลิกส่งออกแล้วเลือกรูปแบบที่ต้องการ

## ความเป็นส่วนตัว

แอปนี้:

- อ่านข้อมูลจากแอป Apple Stocks เท่านั้น
- ไม่เชื่อมต่ออินเทอร์เน็ต
- ไม่เก็บหรือส่งข้อมูลใดๆ ออกไป
- ประมวลผลทั้งหมดภายในเครื่อง Mac ของคุณ
