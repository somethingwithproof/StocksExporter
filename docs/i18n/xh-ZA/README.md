# Stocks Exporter

[![Quality Gate Status](https://sonarcloud.io/api/project_badges/measure?project=somethingwithproof_StocksExporter&metric=alert_status)](https://sonarcloud.io/summary/new_code?id=somethingwithproof_StocksExporter)
[![License](https://img.shields.io/badge/license-MIT-blue)](../../../LICENSE)
[![OpenSSF Scorecard](https://api.scorecard.dev/projects/github.com/somethingwithproof/StocksExporter/badge)](https://scorecard.dev/viewer/?uri=github.com/somethingwithproof/StocksExporter)

Usetyenziso lwemveli lwe-macOS lokuthumela uluhlu lwakho lokubeka iliso lwe-Apple Stocks kwifomathi ye-CSV okanye ye-JSON.

I-Apple ayiboneleli ngendlela esemthethweni yokuthumela idatha yoluhlu lwakho lokubeka iliso lwe-Stocks. Olu setyenziso lusombulula loo ngxaki ngokusebenzisa iindlela ezimbini eziphelelisana:

1. **I-API Yofikeleleko (Accessibility API)** — Ifunda ujongano lwe-Stocks.app olusebenzayo ngexesha langempela
2. **Ugcino Lwexeshana Lwewijethi (Widget Cache)** — Icazulula iifayile zogcino lwexeshana ezigcinwe kwindawo yakho xa usetyenziso lungasebenzi

## Iimpawu

- **Ujongano lwemveli lwe-SwiftUI** oluxhasa imo emnyama kunye noyilo lwe-RTL
- **Imithombo emininzi yedatha** — I-API Yofikeleleko okanye ukucazululwa kogcino lwexeshana
- **Ukuthumela kwi-CSV okanye kwi-JSON** ngeikholamu ezinokulungiswa
- **Umboniso wangaphambili phambi kokuthumela** — Bona kanye oko ukuthumelayo
- **Ukukhetha iikholamu** — Khetha iinkalo zedatha ofuna ukuzibandakanya
- **Kopa kwibhodi yokukopa** — Ukuthumela ngokukhawuleza ngaphandle kokugcina ifayile
- **Izikhetho ezihlala zikhona** — Igcina iisetingi zakho zokuthumela
- **Ujongano oluguqulelwe kwiilwimi** — Lufumaneka ngeelwimi ezingama-45

## Iilwimi Ezixhaswayo

I-Stocks Exporter isebenzisa izikhetho zolwimi lwesixokelelwano se-macOS kwaye ibandakanya uguqulelo olupheleleyo lweelwimi ezingama-45 (kuquka inkxaso ezenzekelayo yoyilo lwasekunene ukuya ekhohlo yesi-Arabhu, isiPersi, isiHebhere, nesi-Urdu). Jonga uluhlu olupheleleyo kwi-[README yesiNgesi](../../../README.md#supported-languages).

## Iimfuno

- macOS 14.0 (Sonoma) okanye entsha
- Imvume Yofikeleleko (yedatha ephilayo evela kwi-Stocks.app)

## Ukwakha

```bash
swift build
swift run
```

Okanye vula kwi-Xcode uze wakhe.

## Ukusetyenziswa

1. Qalisa usetyenziso
2. Nika imvume Yofikeleleko xa ucelwa (yedatha ephilayo)
3. Vula usetyenziso lwe-Apple Stocks (ngokuzithandela, ukufumana iziphumo ezilungileyo)
4. Cofa u-Hlaziya ukufaka uluhlu lwakho lokubeka iliso
5. Khetha izabelo (okanye uthumele zonke)
6. Cofa u-Thumela uze ukhethe ifomathi yakho
