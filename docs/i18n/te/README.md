# Stocks Exporter

[![Quality Gate Status](https://sonarcloud.io/api/project_badges/measure?project=somethingwithproof_StocksExporter&metric=alert_status)](https://sonarcloud.io/summary/new_code?id=somethingwithproof_StocksExporter)
[![License](https://img.shields.io/badge/license-MIT-blue)](../../../LICENSE)
[![OpenSSF Scorecard](https://api.scorecard.dev/projects/github.com/somethingwithproof/StocksExporter/badge)](https://scorecard.dev/viewer/?uri=github.com/somethingwithproof/StocksExporter)

మీ Apple Stocks వీక్షణ జాబితాను CSV లేదా JSON ఫార్మాట్‌కు ఎగుమతి చేయడానికి ఒక నేటివ్ macOS యాప్.

మీ Stocks వీక్షణ జాబితా డేటాను ఎగుమతి చేయడానికి Apple అధికారిక మార్గాన్ని అందించదు. ఈ యాప్ రెండు పూరక పద్ధతులను ఉపయోగించి ఆ సమస్యను పరిష్కరిస్తుంది:

1. **ప్రాప్యత API (Accessibility API)** — నడుస్తున్న Stocks.app ఇంటర్‌ఫేస్‌ను రియల్-టైమ్‌లో చదువుతుంది
2. **విడ్జెట్ కాష్ (Widget Cache)** — యాప్ నడవని సమయంలో స్థానికంగా నిల్వ చేయబడిన కాష్ ఫైళ్లను పార్స్ చేస్తుంది

## ఫీచర్లు

- **నేటివ్ SwiftUI ఇంటర్‌ఫేస్** — డార్క్ మోడ్ మరియు RTL లేఅవుట్ మద్దతుతో
- **బహుళ డేటా మూలాలు** — ప్రాప్యత API లేదా కాష్ పార్సింగ్
- **CSV లేదా JSON ఎగుమతి** — అనుకూలీకరించదగిన నిలువు వరుసలతో
- **ఎగుమతికి ముందు ముందస్తు వీక్షణ** — మీరు సరిగ్గా ఏమి ఎగుమతి చేస్తున్నారో చూడండి
- **నిలువు వరుసల ఎంపిక** — ఏ డేటా ఫీల్డ్‌లను చేర్చాలో ఎంచుకోండి
- **క్లిప్‌బోర్డ్‌కు కాపీ చేయండి** — ఫైల్ సేవ్ చేయకుండా వేగంగా ఎగుమతి చేయండి
- **స్థిరమైన ప్రాధాన్యతలు** — మీ ఎగుమతి సెట్టింగ్‌లను గుర్తుంచుకుంటుంది
- **స్థానికీకరించిన ఇంటర్‌ఫేస్** — 45 భాషల్లో అందుబాటులో ఉంది

## మద్దతు ఉన్న భాషలు

Stocks Exporter macOS సిస్టమ్ భాషా ప్రాధాన్యతలను ఉపయోగిస్తుంది మరియు 45 భాషలకు పూర్తి UI స్థానికీకరణను కలిగి ఉంది (అరబిక్, పర్షియన్, హీబ్రూ మరియు ఉర్దూ కోసం స్వయంచాలక కుడి-నుండి-ఎడమ లేఅవుట్ మద్దతుతో). పూర్తి జాబితా కోసం [ఇంగ్లీష్ README](../../../README.md#supported-languages) చూడండి.

## అవసరాలు

- macOS 14.0 (Sonoma) లేదా ఆపై వెర్షన్
- ప్రాప్యత అనుమతి (Stocks.app నుండి లైవ్ డేటా కోసం)

## బిల్డ్ చేయడం

```bash
swift build
swift run
```

లేదా Xcode లో తెరిచి బిల్డ్ చేయండి.

## వినియోగం

1. యాప్‌ను ప్రారంభించండి
2. అడిగినప్పుడు ప్రాప్యత అనుమతి ఇవ్వండి (లైవ్ డేటా కోసం)
3. Apple Stocks యాప్‌ను తెరవండి (ఐచ్ఛికం, ఉత్తమ ఫలితాల కోసం)
4. మీ వీక్షణ జాబితాను లోడ్ చేయడానికి రిఫ్రెష్ క్లిక్ చేయండి
5. షేర్లను ఎంచుకోండి (లేదా అన్నీ ఎగుమతి చేయండి)
6. ఎగుమతి క్లిక్ చేసి మీ ఫార్మాట్‌ను ఎంచుకోండి

## గోప్యత

ఈ యాప్:

- Apple Stocks యాప్ నుండి మాత్రమే డేటాను చదువుతుంది
- ఇంటర్నెట్‌కు కనెక్ట్ కాదు
- ఏ డేటాను సేకరించదు లేదా పంపదు
- మొత్తం ప్రాసెసింగ్ మీ Mac లో స్థానికంగా జరుగుతుంది
