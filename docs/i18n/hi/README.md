# Stocks Exporter

[![Quality Gate Status](https://sonarcloud.io/api/project_badges/measure?project=somethingwithproof_StocksExporter&metric=alert_status)](https://sonarcloud.io/summary/new_code?id=somethingwithproof_StocksExporter)
[![License](https://img.shields.io/badge/license-MIT-blue)](../../../LICENSE)
[![OpenSSF Scorecard](https://api.scorecard.dev/projects/github.com/somethingwithproof/StocksExporter/badge)](https://scorecard.dev/viewer/?uri=github.com/somethingwithproof/StocksExporter)

अपनी Apple Stocks निगरानी सूची को CSV या JSON प्रारूप में निर्यात करने के लिए एक नेटिव macOS ऐप।

Apple आपकी Stocks निगरानी सूची का डेटा निर्यात करने का कोई आधिकारिक तरीका प्रदान नहीं करता है। यह ऐप दो पूरक तरीकों का उपयोग करके इस समस्या को हल करता है:

1. **सुगम्यता API (Accessibility API)** — चल रहे Stocks.app इंटरफ़ेस को रीयल-टाइम में पढ़ता है
2. **विजेट कैश (Widget Cache)** — ऐप न चलने पर स्थानीय रूप से संग्रहीत कैश फ़ाइलों को पार्स करता है

## विशेषताएँ

- **नेटिव SwiftUI इंटरफ़ेस** डार्क मोड और RTL लेआउट समर्थन के साथ
- **एकाधिक डेटा स्रोत** — सुगम्यता API या कैश पार्सिंग
- **CSV या JSON में निर्यात** अनुकूलन योग्य स्तंभों के साथ
- **निर्यात से पहले पूर्वावलोकन** — देखें कि आप वास्तव में क्या निर्यात कर रहे हैं
- **स्तंभ चयन** — चुनें कि कौन-से डेटा फ़ील्ड शामिल करने हैं
- **क्लिपबोर्ड पर कॉपी करें** — फ़ाइल सहेजे बिना त्वरित निर्यात
- **स्थायी प्राथमिकताएँ** — आपकी निर्यात सेटिंग्स याद रखता है
- **स्थानीयकृत इंटरफ़ेस** — 45 भाषाओं में उपलब्ध

## समर्थित भाषाएँ

Stocks Exporter macOS सिस्टम भाषा प्राथमिकताओं का उपयोग करता है और 45 भाषाओं के लिए पूर्ण UI स्थानीयकरण प्रदान करता है (अरबी, फ़ारसी, हिब्रू और उर्दू के लिए स्वचालित दाएँ-से-बाएँ लेआउट समर्थन सहित)। पूरी सूची के लिए [अंग्रेज़ी README](../../../README.md#supported-languages) देखें।

## आवश्यकताएँ

- macOS 14.0 (Sonoma) या उसके बाद का संस्करण
- सुगम्यता अनुमति (Stocks.app से लाइव डेटा के लिए)

## बिल्ड करना

```bash
swift build
swift run
```

या Xcode में खोलें और बिल्ड करें।

## उपयोग

1. ऐप खोलें
2. संकेत मिलने पर सुगम्यता अनुमति दें (लाइव डेटा के लिए)
3. Apple Stocks ऐप खोलें (वैकल्पिक, सर्वोत्तम परिणामों के लिए)
4. अपनी निगरानी सूची लोड करने के लिए ताज़ा करें पर क्लिक करें
5. स्टॉक चुनें (या सभी निर्यात करें)
6. निर्यात करें पर क्लिक करें और अपना प्रारूप चुनें

## गोपनीयता

यह ऐप:

- केवल Apple के Stocks ऐप से डेटा पढ़ता है
- इंटरनेट से कनेक्ट नहीं होता है
- कोई भी डेटा एकत्र या प्रसारित नहीं करता है
- सारी प्रक्रिया आपके Mac पर स्थानीय रूप से होती है
