# Stocks Exporter

[![Quality Gate Status](https://sonarcloud.io/api/project_badges/measure?project=somethingwithproof_StocksExporter&metric=alert_status)](https://sonarcloud.io/summary/new_code?id=somethingwithproof_StocksExporter)
[![License](https://img.shields.io/badge/license-MIT-blue)](../../../LICENSE)
[![OpenSSF Scorecard](https://api.scorecard.dev/projects/github.com/somethingwithproof/StocksExporter/badge)](https://scorecard.dev/viewer/?uri=github.com/somethingwithproof/StocksExporter)

یک برنامه بومی macOS برای خروجی گرفتن از فهرست پیگیری Apple Stocks شما با قالب CSV یا JSON.

اپل هیچ روش رسمی برای خروجی گرفتن از داده‌های فهرست پیگیری برنامه Stocks ارائه نمی‌دهد. این برنامه این مشکل را با دو روش مکمل حل می‌کند:

1. **رابط برنامه‌نویسی دسترسی‌پذیری (Accessibility API)** — رابط کاربری برنامه در حال اجرای Stocks.app را به‌صورت زنده می‌خواند
2. **حافظه پنهان ویجت (Widget Cache)** — هنگامی که برنامه باز نیست، فایل‌های حافظه پنهان ذخیره‌شده به‌صورت محلی را تجزیه می‌کند

## ویژگی‌ها

- **رابط کاربری بومی SwiftUI** با پشتیبانی از حالت تاریک و چیدمان راست‌به‌چپ (RTL)
- **منابع داده متعدد** — رابط دسترسی‌پذیری یا تجزیه حافظه پنهان
- **خروجی با قالب CSV یا JSON** با ستون‌های قابل سفارشی‌سازی
- **پیش‌نمایش پیش از خروجی** — دقیقاً ببینید چه داده‌ای را خروجی می‌گیرید
- **انتخاب ستون‌ها** — فیلدهای داده‌ای مورد نظر برای خروجی را انتخاب کنید
- **کپی در کلیپ‌بورد** — خروجی سریع بدون نیاز به ذخیره فایل
- **تنظیمات ماندگار** — تنظیمات خروجی شما را به خاطر می‌سپارد
- **رابط کاربری بومی‌سازی‌شده** — در دسترس به ۴۵ زبان

## زبان‌های پشتیبانی‌شده

Stocks Exporter از تنظیمات زبان سیستم macOS استفاده می‌کند و شامل بومی‌سازی کامل رابط کاربری برای ۴۵ زبان است (از جمله پشتیبانی خودکار از چیدمان راست‌به‌چپ برای عربی، فارسی، عبری و اردو). برای مشاهده فهرست کامل، [فایل README انگلیسی](../../../README.md#supported-languages) را ببینید.

## پیش‌نیازها

- سیستم‌عامل macOS 14.0 (Sonoma) یا جدیدتر
- مجوز دسترسی‌پذیری (برای خواندن داده‌های زنده از Stocks.app)

## نحوه استفاده

1. برنامه را اجرا کنید
2. در صورت درخواست، مجوز دسترسی‌پذیری را اعطا کنید (برای داده‌های زنده)
3. برنامه Apple Stocks را باز کنید (اختیاری، برای بهترین نتیجه)
4. برای بارگیری فهرست پیگیری خود روی «بازآوری» کلیک کنید
5. سهام‌ها را انتخاب کنید (یا از همه خروجی بگیرید)
6. روی «خروجی گرفتن» کلیک کرده و قالب مورد نظر را انتخاب کنید

## حریم خصوصی

این برنامه:

- تنها داده‌ها را از برنامه Apple Stocks می‌خواند
- به اینترنت متصل نمی‌شود
- هیچ داده‌ای را جمع‌آوری یا ارسال نمی‌کند
- تمامی پردازش‌ها را به‌صورت محلی روی مک شما انجام می‌دهد
